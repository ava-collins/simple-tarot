# ReadingListCard

Displays one saved reading summary with monotone question text. Date
formatting happens before data reaches this molecule.

<Canvas of={ReadingListCardStories.Default} />

## Alternate State

<Canvas of={ReadingListCardStories.WithoutQuestion} />

## Palette

Neutral surfaces, text, borders, and actions use the shared black, white, and
grey values from `theme.colors`. Status feedback retains its semantic theme
color.

## Props

- `createdAtLabel`: Already formatted reading timestamp.
- `question`: Display question or caller-provided fallback text.
- `spread`: Reading spread label.
- `summary`: Reading summary text.
