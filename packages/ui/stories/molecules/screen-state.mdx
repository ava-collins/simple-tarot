# ScreenState

Internal presentation-only molecule for full-screen statuses and prompts.
The discriminated `kind` prop keeps status feedback separate from prompt
title/body/feedback composition.

`ScreenState` composes `FeedbackText` and `Button`, owns the shared centered
monotone layout, and exposes no style or color escape hatch. Screens continue
to provide `MobileView`, state precedence, copy, and callbacks.
