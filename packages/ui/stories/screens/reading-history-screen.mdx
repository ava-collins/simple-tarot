# ReadingHistoryScreen

Mobile reading history screen wrapped in `MobileView`. It receives signed-in state, display-ready readings, and navigation callbacks from the route layer.

Auth loading and signed-out presentation use the shared `ScreenState`
molecule. Errors shown alongside populated history remain inline
`FeedbackText`.

## Responsibilities

- Shows auth loading and signed-out states.
- Renders the saved-reading header with monotone text.
- Composes `ScreenState` for full-screen auth states.
- Delegates list, empty, and refresh presentation to `ReadingHistoryList`.
