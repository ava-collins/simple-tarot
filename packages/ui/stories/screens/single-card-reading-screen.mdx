# SingleCardReadingScreen

Mobile "tap to draw" screen wrapped in `MobileView`. Wraps the `NewReading` organism unmodified and layers in auth, generating, and error presentation around it.

Loading states use muted `FeedbackText`, errors use semantic `FeedbackText`,
and sign-in/retry actions use standard primary `Button` atoms. Screen-state
structures remain local until checkpoint 4.

## Palette

Neutral surfaces, text, borders, and actions use the shared black, white, and
grey values from `theme.colors`. Status feedback retains its semantic theme
color.

## Responsibilities

- Shows auth loading and signed-out states.
- Blocks double taps while a reading is generating.
- Surfaces an atom-backed error with a retry action.
- Delegates the tap-to-draw interaction to the `NewReading` organism.
